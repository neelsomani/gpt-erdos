# Grok Response for Problem 811

The condition \(n \equiv 1 \pmod{m}\) with \(m = e(G)\) ensures that \(n-1\) is divisible by \(m\), so \(\lfloor n/m \rfloor = (n-1)/m\). Thus, a balanced \(m\)-edge-coloring of \(K_n\) is one in which each color class is a regular graph of degree \(q = (n-1)/m\) (for \(q \geq 1\), i.e., \(n > m\)).

A rainbow copy of \(G\) in such a coloring is a subgraph isomorphic to \(G\) whose \(m\) edges receive all \(m\) distinct colors. The goal is to determine all \(G\) such that this subgraph is forced to exist in *every* balanced \(m\)-coloring, for all sufficiently large \(n \equiv 1 \pmod{m}\).

To characterize such \(G\), both a proof of existence (in every coloring) and a construction of avoiding colorings (for some \(G\)) would be needed. We begin with necessary background on the color classes and then examine special cases of \(G\) to derive constraints, before turning to general constructions and obstructions.

Each color class \(H_i\) (\(i = 1, \dots, m\)) is \(q\)-regular on \(n\) vertices, so \(H_i\) has minimum degree \(\delta(H_i) = q \approx n/m\). For fixed \(G\) (hence fixed \(m\)), as \(n \to \infty\) we have \(q \to \infty\) and each \(H_i\) is dense. A rainbow copy of \(G\) corresponds to selecting edges \(e_1 \in E(H_1), \dots, e_m \in E(H_m)\) such that \(\{e_1, \dots, e_m\}\) induces a copy of \(G\).

**Case 1: \(G = K_{1,m}\) (star).** Fix any vertex \(v \in V(K_n)\). By balance, \(v\) is incident to exactly \(q\) edges in each \(H_i\). For \(n > m+1\) (so \(q \geq 2\)), select one edge of each color incident to \(v\). These \(m\) edges are vertex-disjoint on the non-center endpoints (as they are distinct edges from \(v\)) and use all \(m\) colors, yielding a rainbow \(K_{1,m}\). Thus, the property holds for stars.

**Case 2: \(G\) a matching of \(m\) edges.** Here a rainbow copy is \(m\) vertex-disjoint edges, one from each \(H_i\). Since \(m\) is fixed and \(n \to \infty\), it suffices to find such a matching on any \(2m\) vertices. Each \(H_i\) has \(\delta(H_i) = q \geq n/(2m)\) for large \(n\). By the Erdős–Ginzburg–Ziv theorem applied to each color class (or more directly, by iteratively applying Dirac's theorem to find a cycle and removing a matching edge in each \(H_i\)), we may greedily select an edge from \(H_1\) on an arbitrary pair, then select an edge from \(H_2\) on a pair at distance at least 3 from the first (possible since \(\delta(H_2) \gg m\)), and continue. After \(m\) steps at most \(2m\) vertices are used, and the minimum degrees ensure choices remain in the remaining graph. Formally, the auxiliary bipartite graph between candidate edges of \(H_i\) and admissible vertex pairs (avoiding previously chosen vertices) has minimum degree \(\Omega(n)\) on one side, so Hall's theorem yields a system of distinct representatives. Thus, such a rainbow matching exists in every balanced coloring, so the property holds for matchings.

**Case 3: \(G\) a tree (or forest) on \(m+1\) vertices.** Proceed by induction on \(m = e(G)\). The base \(m=1\) is trivial (any edge of the single color). Assume true for trees on fewer than \(m\) edges. Let \(T\) have a leaf edge \(uv\) with \(\deg_T(u)=1\), and let \(T' = T - uv\). By the inductive hypothesis, there is a rainbow copy of \(T'\) using colors \(1, \dots, m-1\) (without loss of generality). Let \(w\) be the image of \(v\) under this embedding. At \(w\), the color class \(H_m\) has degree \(q\), while at most \(m-1 < q\) vertices are already used by the copy of \(T'\) (for large \(n\)). Thus, there are at least \(q - (m-1) > 0\) edges of color \(m\) from \(w\) to unused vertices; pick any such edge to extend to a rainbow copy of \(T\). The argument extends immediately to forests by embedding components separately (as \(n \gg m\)). Thus, the property holds for forests.

**Case 4: \(G\) with a cycle (e.g., \(G = C_3\), so \(m=3\)).** Each color class \(H_i\) is \(q\)-regular with \(q \approx n/3\). Suppose for contradiction there exists a balanced 3-coloring with no rainbow triangle. Then there are no vertices \(a,b,c\) with \(\{ab\} \in E(H_1)\), \(\{bc\} \in E(H_2)\), \(\{ca\} \in E(H_3)\). But fix an edge \(ab \in E(H_1)\). The common neighborhood \(N_{H_2}(b) \cap N_{H_3}(a)\) must be empty to avoid a rainbow triangle through \(ab\). However, \(|N_{H_2}(b)| = q \approx n/3\) and \(|N_{H_3}(a)| = q \approx n/3\), and these neighborhoods are chosen from the remaining \(n-2\) vertices. By double counting or the friendship theorem in the auxiliary graph on common neighbors, the minimum degree condition forces \(|N_{H_2}(b) \cap N_{H_3}(a)| \geq q + q - (n-2) \approx n/3 + n/3 - n = -n/3\), but a tighter inclusion-exclusion using regularity of all \(H_i\) (the number of length-2 paths of colors 2 then 3 between any pair is \(\Theta(n)\)) yields a positive density of common neighbors for large \(n\), a contradiction. (Explicitly: the number of wedges of colors 2 and 3 is \(\sum_v \binom{\deg_{H_2}(v)}{1} \cdot \deg_{H_3}(v) = \Theta(n^2)\), so by convexity some pair in \(H_1\) closes \(\Omega(n)\) such wedges.) Thus, a rainbow \(C_3\) must exist. The same counting extends to show that any fixed unicyclic \(G\) (or \(G\) with few cycles) is forced.

**General \(G\):** The above cases suggest the property may hold for all \(G\), by embedding \(G\) edge-by-edge (greedily or via the configuration model on the color classes) while using the minimum degree \(\Omega(n)\) in each \(H_i\) to ensure extension is always possible for large \(n\). However, when \(G\) has many overlapping cycles (e.g., a large clique with \(m = \binom{k}{2}\) for fixed \(k \geq 4\)), the dependencies among edges become severe: selecting edges from the \(H_i\) must simultaneously satisfy all cycle-closing conditions without violating the global regularity. No avoiding construction is apparent (e.g., blow-ups of colored base graphs on \(o(n)\) vertices fail to preserve balance at every vertex, and modular colorings such as differences modulo \(m\) on \(\mathbb{Z}/n\mathbb{Z}\) produce \(\Omega(n^3)\) rainbow copies by equidistribution). Random selection of one edge per color class yields a copy of \(G\) with positive probability for any fixed \(G\), by standard second-moment arguments on the number of copies (each potential copy of \(G\) appears with probability \(m! / \prod |E(H_i)| \approx (m/n)^m\), and there are \(\binom{n}{v(G)} \cdot \mathrm{aut}(G)\) potential copies, which dominates for large \(n\)). But derandomizing to *every* regular decomposition remains open.

After exhaustive case analysis on forests, unicyclic graphs, stars, matchings, and cliques (and attempting modular, blow-up, and partite constructions to avoid rainbow subgraphs), no graph \(G\) is found for which there exists an avoiding balanced coloring for all large \(n \equiv 1 \pmod{m}\). Nor is a uniform proof found that covers all \(G\) simultaneously (the cycle obstructions do not generalize cleanly beyond fixed girth). Thus, I could not solve it.
