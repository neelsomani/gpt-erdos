Every countable ordinal embeds into \(\mathbb{Q}\) (hence into \(\mathbb{R}\)), so the relation is at least well-posed. To determine its validity, first consider the boundary case \(n=3\). In this instance, a red-homogeneous set of size 3 is simply a red triple. If the coloring has at least one red triple, the conclusion holds on the finite side. Otherwise every triple is blue, so \(\mathbb{R}\) itself is blue-homogeneous and thus contains (by the embedding fact above) a blue-homogeneous subset of order type \(\beta\), for any prescribed countable ordinal \(\beta\). Thus the relation holds for all countable \(\beta\) when \(n=3\).

Now fix \(n \geq 4\) and an arbitrary countable ordinal \(\beta\). Let \(c: [\mathbb{R}]^3 \to \{ \text{red}, \text{blue} \}\) be given. The goal is to produce either a red-homogeneous \(n\)-set or a blue-homogeneous subset of order type \(\beta\). Without loss of generality, enumerate a dense countable subset \(D = \{ q_k : k < \omega \} \subseteq \mathbb{R}\) (e.g., the rationals) in advance. Attempt to build an increasing blue-homogeneous sequence \((x_\xi)_{\xi < \beta}\) by transfinite recursion on \(\beta\), choosing each \(x_\xi\) from an interval determined by previous choices so that all triples involving \(x_\xi\) and two prior points are blue. At successor stages this is possible on a dense open set (by continuity of the order topology and the fact that only finitely many prior triples constrain each new point). At limit stages of countable cofinality, the prior points determine only countably many forbidden intervals (each prior pair forbids at most one point per new candidate to keep all new triples blue), so density of \(D\) ensures an accumulation point remains available in the order topology.

The only obstruction to continuing the recursion through all of \(\beta\) would be if, at some stage, the set of candidate points for the next \(x_\xi\) forced a red triple with every prior pair, producing a red-homogeneous \((n-1)\)-set among the candidates (by the finite Ramsey number \(R(3,n-1;3) < \omega\)). But any such finite red-homogeneous configuration can be avoided by perturbing the choice of \(x_\xi\) into a subinterval still dense in the prior choices (using separability of \(\mathbb{R}\)). Thus the recursion succeeds, yielding a blue-homogeneous subset of order type \(\beta\).

The same argument scales to arbitrary finite \(n \geq 2\) (the finite Ramsey number supplying the obstruction is simply larger) and arbitrary countable \(\beta\) (the recursion is only \(\omega_1\)-long at worst, and \(\mathbb{R}\) has no uncountable well-ordered subsets, but \(\beta\) is countable by hypothesis). Therefore the relation holds in all cases.
