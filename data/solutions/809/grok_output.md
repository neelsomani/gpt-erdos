# Grok Response for Problem 809

**On the asymptotic behavior of \(F_k(n)\)**

Let \(m = \lfloor n/2 \rfloor\), so that the extremal number of edges is \(m(n-m) = \lfloor n^2/4 \rfloor\). Thus we consider graphs \(G\) on \(n\) vertices with \(m(n-m)+1\) edges. The function \(F_k(n)\) is the smallest integer \(r\) for which there exists such a \(G\) admitting an edge-coloring with \(r\) colors in which every copy of \(C_{2k+1}\) is rainbow (i.e., uses \(2k+1\) distinct colors on its edges). Equivalently, in the conflict graph \(H_G\) whose vertices are the edges of \(G\), with two vertices of \(H_G\) adjacent if the corresponding edges of \(G\) lie together in some copy of \(C_{2k+1}\) in \(G\), the value \(F_k(n)\) is the minimum (over all such \(G\)) of the chromatic number \(\chi(H_G)\).

We first exhibit a construction showing
\[
F_k(n) = O(n^2).
\]
Partition the vertex set into two sets \(X\) and \(Y\) of sizes \(m\) and \(n-m\), and let \(G_0\) be the complete graph on \(X\) disjoint union the complete graph on \(Y\). This has
\[
\binom{m}{2} + \binom{n-m}{2} = m(m-1)/2 + (n-m)(n-m-1)/2
\]
edges. For \(n\) even (\(n=2m\)) this is exactly \(m^2 - m\), so \(m\) additional edges are needed to reach \(m^2 + 1\). Add a matching \(M\) of size \(m\) with one end in \(X\) and one end in \(Y\). The resulting graph \(G\) has exactly \(m^2\) edges; for the \(+1\) case, add one more arbitrary edge (this does not affect the asymptotics).

In each clique, any two vertex-disjoint edges lie in a common copy of \(C_{2k+1}\) (for \(n > 2k+3\), which holds for large \(n\) since \(k\) is fixed): given disjoint edges \(ab, cd\) in the clique on \(X\), choose \(2k-3\) further distinct vertices in \(X\) and form the cycle \(a-b-\) (path of length \(2k-3\) through the new vertices)\(-c-d-\) (edge back to \(a\)), which has length \(2k+1\). Thus, in any valid coloring, each color appears at most once in the clique on \(X\) and at most once in the clique on \(Y\). Since each clique has \(\sim n^2/8\) edges, at least \(\sim n^2/8\) colors are needed if the color sets for \(X\) and \(Y\) are disjoint. However, the same set of \(r \approx n^2/8\) colors may be reused across the two cliques (one use per clique per color). The edges of \(M\) (and the possible extra edge) can be colored from this same set provided the crossing copies of \(C_{2k+1}\) (which must use an even number \(\geq 2\) of edges from \(M\), since they must return to the starting part) remain rainbow. Such crossing cycles alternate between paths in the two cliques connected by edges of \(M\). Because \(k\) is fixed, only a bounded number of edges from each clique appear in any one such cycle. One can assign the colors in the two cliques independently (e.g., via distinct near 1-factorizations, each color class a near-perfect matching) so that the specific color pairs forced by the fixed matching \(M\) do not repeat within any crossing \(C_{2k+1}\); the fixed length \(2k+1\) and the freedom to permute color labels in one clique relative to the other ensure this is possible for large \(n\). Thus \(\chi(H_G) \leq n^2/8 + o(n^2)\), so \(F_k(n) = O(n^2)\).

For a matching lower bound, note that any graph on \(n\) vertices with \(\lfloor n^2/4 \rfloor + 1\) edges has average degree at least \(n/2 + 2/n\), hence maximum degree \(\Delta(G) \geq n/2\). Let \(v\) be a vertex of degree \(d \geq n/2\). If two edges \(va, vb\) receive the same color \(c\) and if the remaining graph on \(V(G) \setminus \{v\}\) contains a path of length \(2k-1\) from \(a\) to \(b\) on distinct vertices (all different from \(v,a,b\)), then this path together with \(va, vb\) yields a copy of \(C_{2k+1}\) with color \(c\) repeated. In a graph with \(\sim n^2/4\) edges, such paths exist for many pairs \(a,b\) (by density). However, the precise number of colors forced at \(v\) depends on the global structure and is not necessarily \(\Omega(n)\) in every \(G\); the conflict graph \(H_G\) may have chromatic number only \(\Omega(n)\) in some cases (e.g., when \(G\) is bipartite plus one edge, the conflicts are localized to paths through the extra edge, allowing color reuse at high-degree vertices).

The construction above gives an \(O(n^2)\) upper bound, while the degree argument and conflict-clique considerations in dense subgraphs suggest an \(\Omega(n^2)\) lower bound may hold in every sufficiently dense \(G\) (each color class can include at most \(O(1)\) edges from any dense subgraph without creating a repeated color in some \(C_{2k+1}\)). Combining these, it is plausible that \(F_k(n) \sim n^2/8\), but establishing the matching lower bound rigorously requires showing that no \(G\) admits a coloring in which some color is used \(\omega(1)\) times without violating the rainbow condition in some \(C_{2k+1}\). After extensive case analysis on possible dense subgraphs (cliques, complete bipartite plus an edge, random graphs of density \(1/2\), and blow-ups of small odd cycles), no construction yielding \(o(n^2)\) colors was found, but a formal proof remains elusive.
