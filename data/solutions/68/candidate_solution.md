No one knows (as of now).

This exact question is listed as an open Erdős problem (Erdős Problem #68): it asks whether
[
\sum_{n\ge 2}\frac{1}{n!-1}
]
is irrational, and it is still marked **OPEN**. ([Erdős Problems][1])

Terence Tao also explicitly says this irrationality question is “completely open.” ([What's new][2])

For reference, the sum is a well-defined constant (it converges fast) and its value is about
[
1.2534987556999534716433609379\ldots
]
([OEIS][3])

A useful identity (mentioned in the Erdős problem notes) is that you can rewrite it as a double sum:
[
\sum_{n\ge 2}\frac{1}{n!-1}
=\sum_{k\ge 1}\sum_{n\ge 2}\frac{1}{(n!)^k}.
]
([Erdős Problems][1])

So the honest answer is: **it is not proved irrational, and not proved rational either**. ([Erdős Problems][1])
