The reasoning proceeds by first clarifying the relevant notions: a graph G has chromatic number exactly ℵ₁ when it admits a proper vertex-coloring with ℵ₁ colors but admits none with any cardinal ≤ ℵ₀ colors (equivalently, G is not the union of countably many independent sets). A countable subgraph H is infinitely connected when it is n-vertex-connected for every finite n, i.e., for every finite vertex set S ⊂ V(H) with |S| < n the graph H − S remains connected (or, equivalently by Menger’s theorem, every pair of vertices in H − S is linked by n internally vertex-disjoint paths). The claim then asserts that any G with χ(G) = ℵ₁ must contain at least one such H.

To test the claim, first note that it holds for some canonical examples: the complete graph K_ℵ₁ has χ = ℵ₁ and every countable infinite clique subgraph is infinitely connected (removal of any finite vertex set leaves an infinite complete graph, hence connected). Likewise, any graph of chromatic number ℵ₁ that contains a copy of K_ω satisfies the conclusion. For graphs free of large cliques one invokes the classical Erdős–Hajnal construction of triangle-free (in fact arbitrarily high-girth) graphs of chromatic number ℵ₁; each such graph still admits countable subgraphs that are n-connected for all n (for instance, countable bipartite graphs such as the complete bipartite graph K_ω,ω are 2-colorable yet infinitely connected, since deletion of finitely many vertices from either part leaves a connected infinite complete bipartite graph). Thus the absence of an infinitely connected countable subgraph is not forced merely by forbidding finite subgraphs of large chromatic number or by imposing girth restrictions.

A direct proof that every G with χ(G) = ℵ₁ must contain an infinitely connected countable subgraph would proceed by attempting an inductive construction inside G: begin with any vertex v₀, successively adjoin vertices that realize sufficiently many vertex-disjoint paths to all previously chosen vertices (possible because if every countable subset admitted a finite vertex cut, one could hope to derive a countable coloring of G by coloring each “block” separated by successive cuts with a fresh color from ω). However, the finite size of the cut depends on the particular countable subset chosen, so no uniform bound on cut size exists; without such uniformity the inductive construction may fail to produce a single countable set that is simultaneously n-connected for every n, and the attempted coloring need not be proper on the whole uncountable vertex set. Standard compactness arguments (e.g., viewing the collection of all countable subsets as a club filter on ω₁ and attempting a pressing-down argument) also stall, because the property “admits a finite vertex cut” is not closed under countable increasing unions.

A counter-example construction would require an uncountable graph that is not ω-colorable yet every countable induced subgraph admits a finite vertex cut of size bounded by a function of that subgraph. Attempts to build such a graph—e.g., by transfinite induction along ω₁, ensuring at each countable stage that a new vertex is joined only to a finite “cut-set” chosen from earlier vertices—inevitably collapse either to an ω-colorable graph (by assigning each vertex the color of the stage at which its cut-set was fixed) or to a subgraph that evades all finite cuts, contradicting the avoidance requirement. Because both the positive proof strategy and the negative construction strategy encounter these obstructions and no workaround is apparent, the statement remains unresolved.
