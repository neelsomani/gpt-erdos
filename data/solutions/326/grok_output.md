# Grok Response for Problem 326

The problem asks whether every additive basis \(A \subseteq \mathbb{N}\) of order 2 (i.e., \(A + A\) contains all sufficiently large natural numbers) must contain a subset \(B = \{b_1 < b_2 < \cdots\}\) that is also an additive basis of order 2, but for which \(\lim_{k \to \infty} b_k / k^2\) fails to exist (equivalently, \(\liminf_{k \to \infty} b_k / k^2 < \limsup_{k \to \infty} b_k / k^2\)).

First, observe that any additive basis \(A = \{a_1 < a_2 < \cdots\}\) of order 2 necessarily satisfies \(\limsup_{k \to \infty} a_k / k^2 < \infty\). To see this, fix a large \(X\) such that all integers in \([X, 2X]\) lie in \(A + A\). There are \(X\) such integers. Each sum \(a + a'\) with \(a, a' \in A\) and \(a + a' \in [X, 2X]\) requires at least one of \(a, a'\) to lie in \([1, 2X]\), so
\[
|(A + A) \cap [X, 2X]| \leq A(2X)^2.
\]
Since the left side is \(X\) (for large \(X\)), it follows that \(A(2X) \gg \sqrt{X}\). Setting \(k = A(2X)\), we have \(a_k \leq 2X\), and thus \(X \ll k^2\), which rearranges to \(a_k \ll k^2\). In other words, \(\limsup_{k \to \infty} a_k / k^2 < \infty\).

If \(\liminf_{k \to \infty} a_k / k^2 < \limsup_{k \to \infty} a_k / k^2\), then \(A\) itself satisfies the required conclusion (with \(B = A\)). Thus, it suffices to consider the case in which \(\lim_{k \to \infty} a_k / k^2 = c\) exists for some finite \(c > 0\), and to ask whether a suitable subset \(B \subseteq A\) with a strictly smaller liminf (but still finite limsup) must exist.

To construct such a \(B\), one would need to select its elements so that the effective constant in \(b_k \sim \gamma k^2\) (for large blocks of \(k\)) oscillates between two values \(\gamma_1 < \gamma_2\) (both finite). Equivalently, in terms of the counting function \(B(x) = \#(B \cap [1, x])\), one seeks \(B(x) \asymp \sqrt{x / \gamma}\) with \(\gamma\) oscillating between \(\gamma_1\) and \(\gamma_2\) along suitable sequences \(x_j \to \infty\). For \(B + B\) to cover all large integers, it is necessary that \(B(x) \gg \sqrt{x}\) (as above), but this must hold even after thinning \(A\) in intervals where the local density is reduced to achieve the larger \(\gamma_2\).

Suppose we attempt to build \(B\) inductively in dyadic blocks. Let \(X_0 = 1\) and, for \(j \geq 1\), let \(X_j = 2^j\). In blocks where we aim for the smaller effective constant (near \(\gamma_1 < c\)), we include as many elements of \(A \cap [X_{j-1}, X_j]\) as possible (up to the limit imposed by \(A\)). In blocks where we aim for the larger effective constant (near \(\gamma_2 > c\)), we include only a thinned subset, of size roughly \(\sqrt{X_j / \gamma_2} - \sqrt{X_{j-1} / \gamma_2}\). The difficulty is ensuring no gaps are created in \((A + A) \setminus (B + B)\): sums involving one or two terms from a thinned block \([X_{j-1}, X_j]\) must still be representable using elements from other blocks (or the current one). This requires careful alignment of the blocks so that, e.g., intervals of the form \([X_j + X_m, X_{j+1} + X_{m+1}]\) for \(m < j\) are still fully covered even if the contribution from the thinned block is reduced. If \(c\) is sufficiently small (so that \(A\) has "excess" density), such realignment might be possible by borrowing representations from denser blocks. However, if \(c\) is at the threshold of what is possible for bases of order 2 (i.e., near the infimum of all achievable \(\limsup a_k / k^2 > 0\)), thinning may force gaps that cannot be filled from within \(A\).

Probabilistic arguments (e.g., randomly thinning \(A \cap [X_j, X_{j+1}]\) with probability depending on whether the \(j\)th block is a "dense" or "thin" one, then derandomizing) fail to control the potential gaps uniformly over all large intervals.
