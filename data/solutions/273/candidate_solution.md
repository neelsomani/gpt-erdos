If you allow **repeated moduli**, then it’s trivially **yes**: for example
[
0\ (\mathrm{mod}\ 4),\ 1\ (\mathrm{mod}\ 4),\ 2\ (\mathrm{mod}\ 4),\ 3\ (\mathrm{mod}\ 4)
]
covers all integers, and (4=5-1) with (p=5).

But in the standard Erdős–Graham sense where the question is nontrivial—i.e. you want an **incongruent/distinct** covering system (all moduli different, (>1)) with each modulus of the form (p-1) for a prime (p\ge 5)—this is **open** as of the latest public status I can find. ([Erdős Problems][1])

What *is* known is that if you relax the prime condition to allow (p=3) (so modulus (2) is permitted), then Selfridge found an example “using divisors of (360),” but excluding (p=3) (i.e. forbidding modulus (2)) is exactly the hard part. ([Erdős Problems][1])
