Yes — in fact, **any nonzero polynomial works**.

Example: take (f(z)=1). Then for every (n\ge 1),
[
f^{(n)}(z)\equiv 0 \quad\text{for all }z\in\mathbb C,
]
so for any infinite increasing sequence (n_1<n_2<\cdots),
[
{z:\ f^{(n_k)}(z)=0\text{ for some }k}=\mathbb C,
]
which is certainly everywhere dense.

More generally, if $f$ is a polynomial of degree $d$, then (f^{(n)}\equiv 0) for all (n>d), and every infinite increasing sequence ((n_k)) eventually contains some (n_k>d). Hence the set above is again all of (\mathbb C).
