Write the statement in arrow notation as
[
\omega^\beta \to (\omega^\beta,3)^2,
]
i.e. every red/blue colouring of ([\omega^\beta]^2) yields either a red-homogeneous set of order type (\omega^\beta) [[nomath]](a red $K_{\omega^\beta}$)[[/nomath]] or a blue-homogeneous set of size $3$ (a blue triangle).

What is known for **countable** (\beta) is:

## Values of (\beta) where it holds

* (\beta=1) [[nomath]](so $\alpha=\omega$)[[/nomath]]: holds by the infinite Ramsey theorem (\omega\to(\omega,3)^2).
* (\beta=2) [[nomath]](so $\alpha=\omega^2$)[[/nomath]]: **holds** [[nomath]](Specker, 1957; in fact $\omega^2\to(\omega^2,m)^2$ for all finite $m$)[[/nomath]]. ([Erdős Problems][1])
* (\beta=\omega) [[nomath]](so $\alpha=\omega^\omega$)[[/nomath]]: **holds** [[nomath]](Chang, 1972; with extensions to $\omega^\omega\to(\omega^\omega,m)^2$ for finite $m$)[[/nomath]]. ([Erdős Problems][1])

[[nomath]](Trivially, $\beta=0$ gives $\alpha=1$, where a red $K_1$ always exists.)[[/nomath]]

## Values of (\beta) where it fails

* For **finite** (\beta\ge 3): **fails** [[nomath]](Specker showed $\omega^3\nrightarrow(\omega^3,3)^2$, hence $\omega^m\nrightarrow(\omega^m,3)^2$ for all $3\le m<\omega$)[[/nomath]]. ([Erdős Problems][1])
* More generally, Galvin–Larson proved a strong necessary condition: if (\alpha=\omega^\beta) satisfies (\alpha\to(\alpha,3)^2) with (\beta\ge 3), then (\beta) must be **additively indecomposable**. Equivalently,
  [
  \beta=\omega^\gamma\quad\text{for some }\gamma<\omega_1.
  ]
  In particular, **every** (\beta\ge 3) that is additively *decomposable* [[nomath]]($\beta=\beta_0+\beta_1$ with $\beta_0,\beta_1>0$)[[/nomath]] gives a negative relation (\omega^\beta\nrightarrow(\omega^\beta,3)^2). ([Erdős Problems][1])

So **outside** the small cases (\beta\in{1,2}), the only candidates are powers of (\omega): (\beta=\omega, \omega^2, \omega^3,\dots,\omega^\omega,\dots).

## What remains open

* The **general classification** of which countable (\beta) satisfy (\omega^\beta\to(\omega^\beta,3)^2) is **not known**.
* The standard conjecture (attributed on the problem page to Galvin–Larson) is that **every** additively indecomposable (\beta\ge 3), i.e. every (\beta=\omega^\gamma), should satisfy the relation. ([Erdős Problems][1])
* The “first open case” highlighted in the problem list is (\beta=\omega^2) (i.e. (\alpha=\omega^{\omega^2})). ([Erdős Problems][1])

### A note on (\beta=\omega^2)

Some sources in the literature/lecture notes mention an **unpublished** proof (attributed to Darby) for the case (\omega^{\omega^2}\to(\omega^{\omega^2},3)^2). ([University of Hamburg Mathematics][2])
However, the Erdős problem list you are quoting still records (\beta=\omega^2) as open. ([Erdős Problems][3])

## Bottom line

With current *published/standardly accepted* results:

* **Holds:** (\beta=1,2,\omega).
* **Fails:** all finite (\beta) with (3\le\beta<\omega); and more generally any (\beta\ge 3) that is not of the form (\omega^\gamma).
* **Open (in general):** (\beta=\omega^\gamma) for (\gamma\ge 2), starting at (\beta=\omega^2). ([Erdős Problems][1])
