This is a famous open problem.

Your question is exactly the **Erdős similarity problem / Erdős similarity conjecture**: an infinite set (A\subset\mathbb R) is called *universal (in measure)* if **every** measurable set (E\subset\mathbb R) with positive Lebesgue measure contains some nontrivial affine copy $aA+b$ [[nomath]](with $a\neq 0$)[[/nomath]]. Erdős asked whether any *infinite* universal sets exist. Equivalently: **for every infinite (A), does there exist a positive‑measure $E$ that contains no (aA+b)?** ([Erdős Problems][1])

## What is known

* If $A$ is **unbounded**, the answer is trivially “yes”: take (E=[0,1]). No affine copy of an unbounded set can fit inside a bounded set. ([Erdős Problems][1])

* If $A$ is **dense in some interval**, the answer is also “yes” (one can take a positive‑measure set with empty interior / nowhere dense, so it cannot contain a dense-in-an-interval subset). This reduction is explicitly noted in the standard discussion of the problem. ([Erdős Problems][1])

* Many other special cases are known (for instance, “slowly decreasing” sequences are known to be non-universal), but not the hard “fast decay” cases. ([arXiv][2])

## What remains open

The conjecture is **still open in general**, and it is open even for very concrete choices like the **geometric sequence**
[
A={1,1/2,1/4,1/8,\dots},
]
and other exponentially decaying sequences. ([Erdős Problems][1])

(There was a 2020 arXiv preprint claiming a full proof, but it was later **withdrawn** because a gap was found.) ([arXiv][3])

## Bottom line

**We do not currently know** whether such an $E$ must exist for *every* infinite (A\subset\mathbb R). It is conjectured “yes” (Erdős’s conjecture), but the general case is open. ([Erdős Problems][1])
