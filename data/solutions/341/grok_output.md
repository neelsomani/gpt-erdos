# Grok Response for Problem 341

The construction begins with a finite initial segment \(A = \{a_1 < \cdots < a_k\}\) of positive integers and extends it greedily: \(a_{n+1}\) is the smallest integer strictly larger than \(a_n\) that cannot be expressed as \(a_i + a_j\) for any \(1 \leq i, j \leq n\). The resulting set \(\overline{A}\) is sum-free, in the sense that there do not exist \(a, b, c \in \overline{A}\) (not necessarily distinct) with \(a \leq b < c\) and \(a + b = c\). To see this, suppose toward a contradiction that such \(a, b, c\) exist. Let \(c = a_m\). Then \(a, b \in \{a_1, \dots, a_{m-1}\}\), so \(c\) would have been forbidden when it was selected as the greedy choice, a contradiction.

The question is whether the sequence of gaps \((d_m)_{m \geq 1}\) with \(d_m = a_{m+1} - a_m\) is eventually periodic, i.e., whether there exist \(M \geq 0\) and \(p \geq 1\) such that \(d_{m+p} = d_m\) for all \(m \geq M\).

To investigate, first consider initial sets consisting of a single element \(m \geq 1\). For \(m = 1\), the construction yields \(\overline{A} = \{1, 3, 5, 7, \dots \}\) (all odd positive integers), since the sum of any two odds is even. The gaps are \(d_m = 2\) for all \(m \geq 1\), which is periodic with period 1.

For \(m = 2\), the construction begins \(2, 3\) (skipping \(4 = 2 + 2\)). All subsequent terms lie in residue classes \(2, 3 \pmod{5}\), as these classes are closed under the greedy choice: if \(S_n \subseteq \{ n \in \mathbb{Z}^+ : n \equiv 2, 3 \pmod{5} \}\), then \(S_n + S_n\) consists only of residues \(4, 0, 1 \pmod{5}\). Thus no integer congruent to \(2\) or \(3 \pmod{5}\) can ever be forbidden by prior sums. The greedy rule therefore selects the next integer congruent to \(2\) or \(3 \pmod{5}\) after the current term, producing the sequence \(2, 3, 7, 8, 12, 13, 17, 18, \dots\). The gaps are \(1, 4, 1, 4, \dots\), periodic with period \(2\) from the outset. (The underlying set is eventually all \(n \geq 2\) with \(n \equiv 2, 3 \pmod{5}\), a sum-free set of density \(2/5\).)

For \(m = 4\), the construction begins by filling \(4, 5, 6, 7\) (no sums are possible below \(8 = 4 + 4\)). All subsequent terms lie in residue classes \(4, 5, 6, 7 \pmod{11}\): if \(S_n\) is contained in these classes, then
\[
S_n + S_n \subseteq \{0, 1, 2, 3, 8, 9, 10\} \pmod{11},
\]
so no element congruent to \(4, 5, 6,\) or \(7 \pmod{11}\) can be forbidden. The greedy rule thus selects the next such integer after the current term, producing blocks of \(4\) consecutive integers spaced periodically with difference \(11\): \(4\)--\(7\), \(15\)--\(18\), \(26\)--\(29\), \(37\)--\(40\), etc. The gaps are eventually \(1, 1, 1, 8\) repeating (period \(4\)). (The underlying set is eventually all \(n \geq 4\) with \(n \equiv 4, 5, 6, 7 \pmod{11}\), a sum-free set of density \(4/11\).)

For general single-element initial sets \(\{m\}\) with \(m \geq 1\), the construction fills an initial block of \(m\) consecutive integers from \(m\) to \(2m-1\) (no sums possible below \(2m\)). It then continues with further blocks of exactly \(m\) consecutive integers, spaced with period \(3m-1\): the \(k\)th block is \([m + (3m-1)k, 2m-1 + (3m-1)k]\) for \(k \geq 0\). The sums of elements from these blocks cover precisely the complementary residues modulo \(3m-1\), so (as above) no term in the allowed residues can be forbidden. The gaps are eventually \(1\) (\(m-1\) times) followed by \(2m\), repeating with period \(m\).

Now consider composite initial sets. For \(\{1, 2\}\), the construction yields \(1, 2, 5, 8, 11, 14, 17, 20, \dots\): after \(2\), all terms are congruent to \(2 \pmod{3}\). With only one element congruent to \(1 \pmod{3}\) (namely \(1\)) and no elements congruent to \(0 \pmod{3}\), the only sum congruent to \(2 \pmod{3}\) possible from the set is \(1 + 1 = 2\). Thus all larger candidates congruent to \(2 \pmod{3}\) are admissible, and the greedy rule selects them consecutively. The gaps are \(1\) followed by \(3\) repeating indefinitely, eventually periodic with period \(1\).

For \(\{2, 3\}\), the construction yields all \(n \geq 2\) congruent to \(2\) or \(3 \pmod{5}\) (as in the \(m=2\) case above), with gaps \(1, 4\) repeating from the first term onward.

For \(\{4\}\), the construction matches the single-element case above (blocks of \(4\) with period \(11\)), with gaps eventually \(1, 1, 1, 8\) repeating. For \(\{9\}\), it fills \(9\)--\(17\), then \(35\)--\(43\), \(61\)--\(69\), \(87\)--\(95\), etc.: blocks of \(9\) consecutive integers with period \(26 = 3 \cdot 9 - 1\), matching the single-element pattern for \(m=9\). The gaps are eventually eight \(1\)'s followed by \(18\), repeating with period \(9\).

In every case examined, \(\overline{A}\) is eventually a union of one or more arithmetic progressions with common difference \(q\) (for some fixed \(q\)), corresponding to a sum-free collection of residue classes modulo \(q\). The gaps are then eventually periodic with period equal to the number of terms per period of length \(q\). The initial segment influences only finitely many terms; once a sufficient run of terms compatible with a sum-free modular pattern has been constructed, the modular obstruction prevents forbidden terms within the allowed classes, and the greedy rule locks into the periodic regime thereafter.

However, while the pattern holds across these examples (including both singletons and composites, small and large starters), a general proof that a compatible modulus \(q\) (and sum-free residue collection modulo \(q\)) is always reached after finitely many steps remains elusive. The gaps \(d_m\) are positive integers, and the sum-free property implies that the density of \(\overline{A}\) (if it exists) is at most \(1/2\). But bounding the gaps uniformly or showing that the "state" of admissible next candidates (relative to prior sums) must eventually cycle in a modular fashion does not follow immediately from these facts, as non-periodic sum-free sets of positive density exist. No counterexample with non-eventually-periodic gaps was found despite extensive case analysis.

Thus, the problem could not be solved.
