Yes.

It’s convenient to package the residue choices into a compact parameter space and then use a standard compactness/uniformity principle (Dini’s theorem). The only nontrivial point is to show that, for each fixed choice of residues, the densities for the *finite truncations* actually tend to $0$.

---

## 1) Put the problem on (\widehat{\mathbb Z})

Let (\widehat{\mathbb Z}) be the profinite completion of (\mathbb Z), with its Haar probability measure (\mu).

For a modulus (n) and a residue (a\pmod n), the set
[
a+n\widehat{\mathbb Z}={x\in\widehat{\mathbb Z}: x\equiv a\pmod n}
]
is clopen, and (\mu(a+n\widehat{\mathbb Z})=1/n).

Fix a choice (a=(a_i)*{i\ge 1}) with (a_i\in\mathbb Z/n_i\mathbb Z). Define
[
C_k(a);:=;\bigcap*{i=1}^k \left(\widehat{\mathbb Z}\setminus (a_i+n_i\widehat{\mathbb Z})\right),
\qquad
C(a);:=;\bigcap_{i=1}^\infty \left(\widehat{\mathbb Z}\setminus (a_i+n_i\widehat{\mathbb Z})\right).
]
So (C_k(a)) is the set of profinite integers avoiding the first $k$ residue classes, and $C(a)$ avoids them all.

Let
[
d_k(a) := \text{(natural density of integers avoiding }a_i !!!\pmod{n_i}\text{ for }1\le i\le k).
]
For fixed $k$, this density exists because the set is periodic with period (\mathrm{lcm}(n_1,\dots,n_k)).

A key observation: for each $k$,
[
d_k(a)=\mu(C_k(a)).
]
Reason: (C_k(a)) is clopen and depends only on congruence classes modulo (\mathrm{lcm}(n_1,\dots,n_k)); the Haar measure of such a set is exactly the fraction of residue classes it occupies, which is also the asymptotic density of its integer points.

Since (C_{k+1}(a)\subseteq C_k(a)) and (\mu) is a genuine measure, we have continuity from above:
[
\mu(C(a))=\lim_{k\to\infty}\mu(C_k(a))=\lim_{k\to\infty} d_k(a).
]
So (\lim_{k} d_k(a)) always exists, and equals (\mu(C(a))).

---

## 2) Show (\mu(C(a))=0) for every $a$

Now use the hypothesis:

> For every choice (a_i\pmod{n_i}), the set of integers avoiding *all* congruences has density $0$.

Equivalently, for every $a$, the set (\mathbb Z\cap C(a)) has density $0$.

Assume for contradiction that for some $a$, (\mu(C(a))=\delta>0).

Consider the rotation/translation (T:\widehat{\mathbb Z}\to\widehat{\mathbb Z}), (T(x)=x+1). This is ergodic with respect to Haar measure (\mu) [[nomath]](intuitively: the subgroup generated by $1$ is dense, so the only measurable sets invariant under $+1$ have measure $0$ or $1$)[[/nomath]].

Apply the Birkhoff ergodic theorem to the integrable function (1_{C(a)}). Since (\mu(C(a))=\delta), for (\mu)-almost every (x\in\widehat{\mathbb Z}),
[
\lim_{N\to\infty}\frac1N\sum_{m=0}^{N-1} 1_{C(a)}(x+m) = \delta.
]
Pick one such $x$.

Now define a new residue choice (b=(b_i)) by
[
b_i \equiv a_i - x \pmod{n_i}.
]
[[nomath]](This makes sense because $x\in\widehat{\mathbb Z}$ has a well-defined reduction modulo $n_i$.)[[/nomath]]

Then (C(b)=C(a)-x). Consequently, for each integer (m),
[
1_{C(b)}(m)=1_{C(a)}(x+m).
]
So the same Birkhoff limit says
[
\lim_{N\to\infty}\frac1N\sum_{m=0}^{N-1} 1_{C(b)}(m) = \delta>0.
]
But the left-hand side is exactly the natural density of integers in $C(b)$, i.e. the density of integers avoiding **all** congruences (b_i\pmod{n_i}).

That contradicts the hypothesis [[nomath]](which says this density must be $0$ for every choice of residue classes)[[/nomath]]. Hence (\delta) cannot be positive, and we conclude:

[
\mu(C(a))=0 \quad\text{for every choice }a.
]

Therefore, for every $a$,
[
\lim_{k\to\infty} d_k(a) = \mu(C(a)) = 0.
]

---

## 3) Upgrade pointwise (\to) uniform using Dini’s theorem

Let
[
X := \prod_{i=1}^\infty (\mathbb Z/n_i\mathbb Z),
]
with the product topology. Each factor is finite discrete, so $X$ is compact (Tychonoff).

For each fixed $k$, the value (d_k(a)) depends only on ((a_1,\dots,a_k)), so (d_k:X\to[0,1]) is continuous [[nomath]](it is constant on cylinders determined by the first $k$ coordinates)[[/nomath]].

Also, (d_{k+1}(a)\le d_k(a)) for all $a$, since adding one more congruence can only remove more integers from the “avoiding” set.

We have shown (d_k(a)\downarrow 0) pointwise on (X), and the limit function $0$ is continuous. By **Dini’s theorem**, the convergence is uniform. That is:
[
\sup_{a\in X} d_k(a) \xrightarrow[k\to\infty]{} 0.
]

Unwinding the definitions, this is exactly your desired conclusion:

> For every (\varepsilon>0) there exists (k) such that for **every** choice of congruence classes (a_i\pmod{n_i}), the density of integers avoiding the first (k) congruences is (<\varepsilon).
